# javascript-racingcar-precourse

## 🛠️ 기능 구현

-   사용자로부터 경주할 자동차 이름 목록을 입력받는다.
-   이름은 쉼표(,)를 기준으로 구분하며, 각 이름의 앞뒤 공백은 제거한다.
-   이름이 1~5자 이내인 경우에만 유효하며, 공백만 있거나 비어 있으면 허용되지 않는다.
-   입력된 이름이 중복될 경우 에러를 발생시킨다.
-   사용자로부터 시도할 횟수를 입력받는다.
-   문자열 형태로 입력받은 값을 정수로 변환하며, 1 이상의 자연수만 허용한다.
-   0 이하이거나 숫자가 아닌 값이 들어올 경우 에러를 발생시킨다.
-   입력받은 이름들을 기반으로 Car 객체 리스트를 생성한다.
-   Car 클래스는 name과 position 속성을 가진다.
-   position은 0으로 초기화되며, move() 메서드가 호출될 때마다 +1씩 증가한다.
-   자동차 경주 라운드를 진행한다.
-   Random.pickNumberInRange(0, 9)를 통해 각 자동차별 무작위 숫자를 생성한다.
-   생성된 숫자가 4 이상일 경우 해당 자동차가 전진(position += 1)한다.
-   라운드는 사용자가 입력한 시도 횟수만큼 반복된다.
-   차수별 실행 결과를 출력한다.
-   한 라운드가 끝날 때마다 모든 자동차의 현재 상태를 출력한다.
-   출력 형식은 "이름 : ---"이며, 전진한 칸 수만큼 - 문자가 출력된다.
-   각 라운드 결과 사이에는 한 줄의 공백을 출력하여 가독성을 높인다.
-   최종 우승자를 계산 및 출력한다.
-   모든 라운드가 종료된 후, 가장 멀리 이동한 자동차(들)를 찾아낸다.
-   여러 자동차가 동일한 최대 거리일 경우, 공동 우승자로 처리한다.
-   출력 형식은 "최종 우승자 : pobi, jun"과 같이 쉼표(,)로 구분하여 표시한다.
-   프로그램의 전체 흐름은 App.js의 run() 메서드에서 제어한다.
-   입력(Console.readLineAsync) → 검증 → 경주 진행 → 출력(Console.print)의 순서로 동작한다.
-   실행 중 예외가 발생하면 [ERROR]로 시작하는 메시지를 출력하고 프로그램을 종료한다.
-   단, process.exit()는 사용하지 않는다.

## 🤔 예외 상황

-   자동차 이름 관련
    -   이름이 5자를 초과하는 경우 → [ERROR] 이름은 1~5자 이내여야 합니다.
    -   이름이 비어 있거나 공백만 입력된 경우 → [ERROR] 이름은 비워둘 수 없습니다.
    -   이름이 중복된 경우 → [ERROR] 중복된 이름이 존재합니다.
    -   쉼표(,)가 연속되거나 마지막에 구분자가 오는 경우 → [ERROR] 잘못된 구분자 배치입니다.
-   시도 횟수 관련
    -   0 이하의 숫자이거나 숫자가 아닌 값 입력 시 → [ERROR] 시도 횟수는 1 이상의 정수여야 합니다.
    -   빈 문자열 입력 시 → [ERROR] 시도 횟수를 입력해야 합니다.
-   경주 로직 관련
    -   무작위 값 생성에 실패하거나 의도치 않은 값(0~9 이외)이 반환될 경우 → [ERROR] 유효하지 않은 난수 값입니다.
    -   자동차 리스트가 비어 있는 경우 → [ERROR] 경주할 자동차가 없습니다.
-   출력 관련
    -   모든 자동차가 한 칸도 움직이지 못한 경우에도 정상적으로 "최종 우승자 : 이름" 출력
    -   출력 중 오류 발생 시 [ERROR] 출력 중 문제가 발생했습니다.
